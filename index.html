SURVIVOR POOL / LOKAL STARTEN

Dein Pool ist
bereit für den Kickoff.

Starte im entpackten Projektordner den kleinen lokalen Server:

python3 server.py

Unter Windows funktioniert meist py server.py.

Survivor Pool öffnen

Der Server speichert Accounts und Tipps und prüft alle Regeln. Das Öffnen einer HTML-Datei allein startet keinen Server. Die vollständige Anleitung findest du in README.md.
